# @alumieye/eyeviz-authoring

Part of [EyeViz](../../README.md) — open-source interactive STEM visualization engine by ALumiEye.

Typed, serializable edit commands on Scene Specifications (add, update, remove, rename,
parameters, steps) with undo/redo. Used by the visual editor; usable by any tool — including
programs that edit scenes on a user's behalf.

> Status: experimental. Not yet published.
